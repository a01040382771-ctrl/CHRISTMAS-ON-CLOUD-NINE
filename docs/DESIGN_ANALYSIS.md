# 레퍼런스 이미지 분석 → 3D 구현 결정

레퍼런스는 AI가 만든 콘셉트 이미지이며 건축 도면이 아닙니다. 분위기·색·조명·건축 언어는 유지하고, 3D 공간으로 걸어 다니기에 문제가 되는 구조는 재설계했습니다. (아래 "관찰"은 이미지를 보고 판단한 것이며 정량 측정이 아닙니다.)

## 1. 유지한 것 (디자인 정체성)

| 요소 | 구현 |
|---|---|
| 파스텔 블루 하늘 + 낮게 깔린 따뜻한 햇빛 | 그라디언트 스카이돔, 따뜻한 `DirectionalLight` + 차가운 `HemisphereLight`, 거리 안개 |
| 솜사탕 같은 구름바다·적운 | 위/아래가 다르게 음영 지는 로브 구름(인스턴싱), 느린 드리프트 |
| 둥글고 작은 건물, 눈 쌓인 돔/원뿔 지붕, 따뜻하게 빛나는 아치 창 | `RoundHouse`(원통 벽 + 돔/양파/원뿔 지붕 + 물결 모양 눈 캡), 창문 글로우 |
| 핑크·크림·버건디·파인그린·샴페인골드 | `world/materials.ts` 한 곳의 팔레트를 모든 건물/소품이 공유 |
| 중앙의 거대한 장식 트리 | 스캘럽 가지 6단 + 오너먼트 + 금빛 리본 + 트윙클 전구 + 별 |
| 빨간 난간이 있는 다리, 떠 있는 작은 섬들 | 아치형 판자 다리(캔디케인 난간), 작은 섬 + 마법의 "소원 나무" |
| 구름 위로 흐르는 폭포, 거친 바위 하부 | 셰이더 폭포, 층리(strata) 정점색 바위 하부 |

## 2. 이미지에서 발견한 문제와 개선

| # | 관찰 (이미지) | 문제 (걸어 다닐 때) | 개선 (3D) |
|---|---|---|---|
| 1 | 왼쪽 건물군이 서로 녹아 붙고 지붕·탑이 겹침 | 어느 벽이 어느 건물인지 불분명, 충돌 불가능 | 건물마다 독립된 풋프린트(원/회전 박스). 테스트로 **건물 간 간격 ≥ 아바타 폭** 검증 |
| 2 | 건물 정면만 정교하고 측·후면이 흐림/불일치 | 카메라를 돌리면 무너짐 | 창·눈 캡·가랜드·처마를 **원둘레 전체**에 생성. 뒷면도 동일 디자인(스크린샷으로 확인) |
| 3 | 문이 없거나 불분명한 건물이 많음 | 출입구 동선 없음 | 모든 건물에 아치 문 + 계단 + 리스 + 랜턴, 문 앞 도착 지점(`ZONES.anchor`)을 보행 가능으로 테스트 |
| 4 | 다리가 건물 중간이나 허공에 닿는 듯 보임 | 건너갈 수 없거나 끼임 | 다리 보행 영역이 **양쪽 섬 안쪽까지 겹치도록** 설계(절벽 여백을 적용해도 연결), 플러드필 테스트로 연결 검증 |
| 5 | 남쪽 나무 부두가 허공으로 끝남, 가장자리 안전장치 없음 | 낙하/막다른 길 | 막다른 부두 제거. 섬 둘레에 캔디케인 난간 + 절벽 여백(0.75 m). 난간은 다리/폭포 위치만 비워 둠 |
| 6 | 지붕/장식이 공중에 떠 있는 부분 | 구조적 설득력 부족 | 모든 지붕에 처마 아래판(soffit), 굴뚝/첨탑은 지붕에서 솟는 구조로 재배치 |
| 7 | 광장이 작고 소품이 빽빽 | 여러 명이 모이기 어려움 | 반경 13.4 m 광장(아바타 폭의 ~17배), 건물 뒤 통로 ≥ 0.9 m 확보(막다른 틈 방지) |
| 8 | 큰 트리 가지가 낮게 내려와 시야를 가림 | 카메라/아바타 가림 | 가지 아래 2.1 m 여유(아바타 1.6 m가 걸어 다님) + 카메라가 트리에 가리면 **캐노피 반투명 페이드** |
| 9 | 섬 하부가 평평하게 잘림 | 입체감 부족 | 바위 하부를 노이즈·드립 크랙·층리 색으로 모델링 |

## 3. 비례 기준

아바타: 높이 1.6 m(모자 포함 ≈1.55), 반경 0.4 m.
- 문 높이 2.85 m(≈1.8배), 창 하단 1.15–1.6 m
- 벤치 좌석 0.5 m, 가로등 3.7 m, 큰 트리 13.5 m
- 보행 속도 4.6 m/s, 절벽 여백 0.75 m(반경 0.4 + 0.35)

## 4. 충돌 ≠ 렌더 (장식 vs 충돌)

충돌은 2D 단순 형상(원/회전 박스) + 보행 가능 영역(원·사각의 합집합)만 사용하고, 창·지붕·가랜드 등 장식은 충돌에 참여하지 않습니다. 같은 데이터(`packages/shared/src/world.ts`)를 서버 검증·클라이언트 예측·3D 배치가 함께 읽어 "눈에 보이는 것 = 부딪히는 것"을 보장합니다.
