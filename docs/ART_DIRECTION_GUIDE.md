# SKY VILLAGE — 3D Art Direction & Building Asset Guide (Draft v1)
> 작성 기준: GitHub 기본 브랜치 `claude/vibrant-euler-nlpnwy`의 `README.md`, `docs/DESIGN_ANALYSIS.md`, `apps/web/src/game/world/materials.ts`, `apps/web/src/game/world/textures.ts`, `apps/web/src/game/buildings/RoundHouse.tsx`, `packages/shared/src/world.ts`.
>
> **범위**: 코드에서 검증된 사실과 제안 규칙을 명확히 구분한다. 로컬의 최신 작업본·실제 화면·모든 건물 컴포넌트는 검증하지 못했다. 이 문서는 **디자인 초안**이며, 건축물 구현 코드는 변경하지 않는다.

## 1. 목표와 아트 방향
- 프로젝트: THE CHRISTMAS AFTERPARTY: SKY VILLAGE
- 경험: 구름 위의 아기자기한 크리스마스 마을을 아바타로 탐험하고 광장·파티장·상점 등에서 교류하는 3D 웹 월드.
- 스타일 키워드: storybook fantasy / stylized 3D / hand-painted-feel / pastel winter / rounded silhouette / burgundy accents / warm window glow.
- 원칙: **읽히는 실루엣 > 자연스러운 동선 > 통일된 재질 > 디테일 밀도**. 개별 건물의 개성은 유지하되 공통 조형 언어를 공유한다.

### 2.2 현재 재질과 질감
- `world/materials.ts`: 대부분 `MeshStandardMaterial`, 기본 `roughness: 0.88`, `metalness: 0`. 단, 금속·리본·눈·유리 등은 별도 값.
- `world/textures.ts`: 외부 이미지 대신 128–512 px 캔버스에서 절차적 텍스처를 생성.
  - **회벽** `plasterTexture()`: 따뜻한 기반색과 부드러운 불규칙 반점/붓 터치 느낌. 벽별 색조만 변경.
  - **목재** `woodTexture()`: 수평 결·곡선형 나뭇결·판자 분할선.
  - **눈** `snowTexture()`: 흰 바탕의 아주 연한 블루/핑크 음영, 무광에 가까움.
  - **조약돌** `cobbleTexture()`: 둥근 파스텔 돌과 밝은 줄눈/눈먼지.
  - **바위** `rockTexture()`: 수평 층리와 반점.
  - **침엽수** `pineTexture()`: 바늘잎 패턴과 녹색 얼룩.
  - **창문** `windowTexture()`: 따뜻한 노란색-주황색 그라디언트, 커튼 옵션.
- `M()` 함수가 공유 머티리얼을 캐시하고 재사용한다. `LIGHTS()`로 공통 전구색도 재사용한다.
- **주의**: 지붕의 실제 타일/목재 지붕결은 현재 공통 머티리얼 표에 명시적 텍스처가 없다. 개별 건축물·지붕 부품의 지오메트리를 추가 확인한 후 결정해야 한다.

### 2.3 현재 형태 규칙
- `RoundHouse.tsx`: 원형 외벽, 곡선형 지붕(dome/cone/onion), 크림 처마 몰딩, 아치 문, 아치 창, 가랜드, 지붕 눈 캡. 후면까지 창과 장식 생성.
- `docs/DESIGN_ANALYSIS.md`: 따뜻한 빛의 창, 버건디/파인그린/샴페인골드, 눈 덮인 둥근 지붕, 구름·폭포·하늘섬과 연결한 디자인 방향이 이미 존재.
- 기준 아바타 높이는 1.6 m, 문 높이 기준은 약 2.85 m. 건물 출입구와 통로는 충돌·동선 기준에 맞춘다.

## 3. 공통 디자인 가이드 — 적용 제안 (미승인 기본안)
1. **실루엣**: 둥글고 부드러운 윤곽, 아치형 출입구/창문, 과도하게 날카로운 모서리 지양. 모든 건물이 동일한 둥근 집이어야 하는 것은 아니다.
2. **색상 역할 분담**: 외벽은 기존 파스텔/크림에서 선택, 지붕은 기존 버건디/레드/틸/파인/블루에서 선택. 트림은 밝은 크림을 일관되게 사용하고, 골드·빨강 리본은 포인트로 제한.
3. **공유 재질**: 외벽·목재·눈·돌·창문의 기존 `M()` 인스턴스 우선 재사용. 새로운 재질이 필요하면 기존 재질과 대비/반사율/텍스처 스케일을 비교한 후 공유 목록에 등록.
4. **질감 밀도**: 큰 면에는 저주파의 부드러운 패턴, 가까운 장식에만 작은 디테일. 동일한 재질에서 텍스처 패턴 크기가 건물마다 달라 보이지 않게 월드 스케일을 맞춘다.
5. **광택**: 회벽·목재·눈은 무광에 가깝게. 금속 장식·전구만 하이라이트 허용. 금속처럼 번쩍이는 회벽과 과도한 노멀맵 지양.
6. **눈 표현**: 지붕 위·처마·난간의 눈은 동일한 흰색/옅은 푸른 음영 규칙을 공유. 눈 두께·곡선·쌓이는 방향은 건물 크기에 따라 비례적으로 조정.
7. **라이팅**: 차가운 겨울 환경광 + 따뜻한 창/전구 조명을 공통으로 사용. 개별 건물마다 서로 다른 색온도/강한 광원을 임의로 추가하지 않는다.
8. **가독성**: 주요 건물은 지붕 형태·입구·대표 장식으로 멀리서 구분. 창·간판·장식이 출입구/동선을 가리지 않도록 한다.
9. **기술**: 공유 재질·지오메트리 재사용, 배치 최적화 유지. 특히 모바일에서 드로우콜/텍스처 메모리 증가를 검토.
10. **변경 관리**: 팔레트·광원·공유 재질을 바꿀 때는 전체 마을 스크린샷(낮/저녁, 원거리/근거리, PC/모바일)으로 재검수.

## 4. 건축물별 모델링 규칙 — 기존 배치에 연결

| ID / 건물 | 코드에서 확인된 형태 또는 공간 | 차별화 방향(제안) | 공통 유지 요소 |
|---|---|---|---|
| `invitation` / Invitation House | 원형 충돌체, 북쪽 배치; `RoundHouse` 적용 여부는 미확인 | 편지·초대장을 연상시키는 명확한 입구/간판, 크림 중심 색상 | 아치 문·창, 공통 회벽·눈·트림 |
| `ballroom` / Velvet Ballroom | 원형 충돌체, 북동쪽 배치 | 가장 우아한 대표 건물; 버건디 포인트와 절제된 골드, 무도회장임을 보여주는 실루엣 | 공통 벽·지붕 팔레트, 따뜻한 창, 동일한 재질 스케일 |
| `market` / Candy Market | 회전 박스 충돌체, 서북쪽 배치 | 상점/캔디의 활기 있는 작은 장식, 잘 읽히는 간판과 진열 | 공통 목재·회벽·눈, 과밀한 장식 제한 |
| `tower` / Moonlit Terrace 관련 탑 | 원형 충돌체, 서쪽 배치. `tower`와 기획 명칭의 1:1 대응은 추가 확인 필요 | 수직 랜드마크, 다른 건물보다 높지만 동일한 지붕·창·트림 언어 | 공통 지붕·석재·조명 |
| `cottage` / 작은 섬의 코티지 | 회전 박스 충돌체, 동쪽 작은 섬 | 작고 아늑한 실루엣, 메인 구역과 동일한 마감 | 동일 팔레트·목재·눈·광원 |

**명칭 확인 필요**: 현재 저장소에는 `Candy Market` 등의 이름이 남아 있지만 최근 기획에는 `Christmas Shop`이 있다. 변경하려면 실제 최신 기획과 코드의 매핑부터 확인한다. 위 표는 최신 로컬 결과를 단정하지 않는다.

### 건물별 Asset Sheet 필수 항목
- 건물 ID / 기획 명칭 / 기능 / 플레이어가 들어가는 정면 방향
- 정면·측면·후면·3/4 레퍼런스와 랜드마크 실루엣
- 높이·폭·출입구 크기(아바타 1.6 m 기준) / 충돌체 및 보행 동선
- 외벽·지붕·트림·목재·창·눈의 **기존 머티리얼 키**; 신규 재질은 별도 승인
- 유일한 장식 1–3가지 / 절제할 장식 목록
- 가까이·멀리·후면에서 검수한 스크린샷
- 마지막 변경일 및 확정 여부(`draft` / `approved`)

## 5. 추천 작업 순서
1. **백업/현황 고정**: 현재 실제 렌더링 스크린샷과 코드 버전 저장.
2. **현황 대조**: 최신 로컬 모델링 시트와 현재 GitHub 기본 브랜치 건물을 1:1 매핑.
3. **대표 모델 확정**: 한 건물을 기준으로 회벽 질감, 지붕의 눈, 목재, 창 조명, 몰딩 규격 확정.
4. **나머지 건물별 적용**: 공통 재질은 재사용하고 고유한 실루엣만 변경.
5. **전체 검수**: 한 화면에서 색·재질·광원·스케일·밀도를 비교.
6. **기능/성능 검수**: 충돌, 출입구 접근, 모바일 렌더링, 드로우콜 회귀 확인.

## 6. 코덱스 지시문 (분석/제안 전용)
```text
Sky Village의 docs/ART_DIRECTION_GUIDE.md를 디자인 기준 초안으로 읽어 주세요.
먼저 실제 현재 브랜치의 buildings 폴더, world/materials.ts, world/textures.ts,
packages/shared/src/world.ts를 조사해서 문서의 사실과 제안을 구분하세요.
기존 건물별 머티리얼 사용 위치를 표로 제시하고 공통 재질로 통일 가능한 항목,
고유 실루엣으로 유지해야 할 항목을 구분하세요.
우선 분석 보고서와 변경 계획만 제안하고 3D 모델링/충돌/배치/기능 코드는 수정하지 마세요.
최근 로컬 디자인 시트가 있다면 그쪽을 최신 디자인 기준으로 비교하세요.
```

## 7. 검수 체크리스트
- [ ] 멀리서도 각 건물의 기능과 출입구가 구분된다.
- [ ] 외벽·목재·눈·지붕의 색감과 텍스처 스케일이 건물 사이에서 일관된다.
- [ ] 후면/측면에도 구조와 장식이 자연스럽게 이어진다.
- [ ] 버건디/골드 포인트가 특정 건물에서 지나치게 많지 않다.
- [ ] 난간·계단·아치문·가랜드가 이동/시야를 방해하지 않는다.
- [ ] 조명 변경에도 회벽/눈이 과도하게 어둡거나 번쩍이지 않는다.
- [ ] PC·모바일에서 주요 오브젝트가 깨지거나 심하게 느려지지 않는다.
- [ ] 새 건축물 추가 시 기존 공통 재질 키를 우선 재사용한다.
