# 호두까기 인형 — 구름 위의 크리스마스

*The Nutcracker on Cloud Nine*: a 30-second 3D short in a gouache style, 1920×1080, 24 fps, with sound.

결과물: [`out/nutcracker.mp4`](out/nutcracker.mp4) · 포스터 프레임: [`out/poster.png`](out/poster.png)

## 재해석: 줄거리

고전 동화에서 클라라가 장난감 크기로 작아지는 장면을 출발점으로 삼았습니다. 그래서 카메라는 처음부터 끝까지 **장난감의 눈높이**에 있고, 거실의 트리·선물·벽난로는 거대한 풍경이 됩니다. 마지막 과자 왕국은 이 저장소의 주제에 맞춰 **구름 위(Cloud Nine)**에 둡니다.

| 시간 | 장면 |
|---|---|
| 0–4.5 s | 자정. 올빼미 괘종시계가 12시를 치고("크리스마스 이브, 자정"), 카메라가 거대한 트리 아래로 내려간다 |
| 4.5–8 s | 금빛 불꽃 속에서 호두까기 인형이 깨어나 턱을 딱딱 부딪치고, 클라라에게 경례한다 |
| 8–13 s | 쥐구멍에서 생쥐들과 생쥐왕이 몰려와 칼싸움이 벌어진다. 클라라가 던진 **슬리퍼**에 맞은 생쥐왕은 왕관을 떨어뜨리고 달아난다 |
| 13–17 s | 마법의 호두가 자라 **호두 껍데기 배**가 된다. 둘이 올라타자 창문이 열리고 배가 밤하늘로 떠오른다 |
| 17–23 s | 눈 내리는 마을과 달을 지나 구름층을 뚫는다. 밤하늘이 새벽빛으로 바뀐다 |
| 23–30 s | 구름 위 과자 왕국. 사탕 성 앞에서 사탕요정이 돌고, 배가 내려앉는다. 타이틀이 붓질로 그려진다 |

## 과슈 룩을 만드는 방법

외부 이미지·모델 에셋은 없습니다. 모든 형태는 three.js 기본 도형으로 코드에서 만들고, 질감은 셰이더로 그립니다.

**표면** ([`src/materials.js`](src/materials.js))
- 부드러운 3단 명암. 그림자는 검게 누르지 않고, 과슈 화가가 그림자를 섞을 때처럼 보라·청색 쪽으로 옮깁니다
- 명암 경계(터미네이터)에 노이즈를 넣어 붓으로 칠한 듯 흔들리게 합니다
- 안료 얼룩, 사탕 줄무늬, 정점에 주는 약간의 "점토 같은 울퉁불퉁함"
- 그림자 맵 대신 발밑에 칠한 보라빛 접지 그림자를 씁니다

**화면 후처리** ([`src/gouache.js`](src/gouache.js))
1. 붓결 왜곡: 획 모양 노이즈 장으로 이미지를 밀어 가장자리를 손그림처럼 흔듭니다
2. 쿠와하라(Kuwahara) 필터: 색을 불투명한 물감 덩어리로 정리합니다
3. 깊이 차이로 그리는 끊어지는 갈색 윤곽선. 인쇄 판이 살짝 어긋난 것처럼 위치를 조금 비켜 둡니다
4. 방향을 가진 붓털 자국으로 명도와 색상을 미세하게 흔듭니다
5. 종이 결, 밝은 부분에서 물감이 비는 드라이 브러시, 크림색 종이 흰색, 남보라 계열 어둠, 고르지 않은 종이 여백
6. 레터링(고운바탕 / 나눔손글씨 펜)을 거친 붓 경계로 칠해 나타나게 합니다

**"투(twos)" 연출**: 붓결과 윤곽이 흔들리는 '보일링', 그리고 캐릭터 포즈는 초당 12번만 바뀝니다. 손으로 그린 애니메이션의 리듬입니다. 카메라는 24 fps로 부드럽게 움직입니다.

**사운드** ([`scripts/score.mjs`](scripts/score.mjs)): 오리지널 오르골풍 왈츠입니다(3/4박, E단조에서 G장조로). 첼레스타 합성음, Karplus-Strong 피치카토, 현악 패드를 쓰고, 괘종 종소리·턱 딱딱·생쥐 찍찍·칼 부딪힘·슬리퍼 "퉁"·바람·썰매 방울 효과음을 장면에 맞춰 넣었습니다. 모두 코드로 합성합니다.

## 실행

```bash
cd film/nutcracker
npm install                 # three.js
npm run preview             # http://localhost:8080 실시간 재생(▶ 클릭, 소리 포함)
node scripts/stills.mjs 5.3 11.9 26   # 특정 시각 스틸 → out/stills/
node scripts/score.mjs      # out/score.wav
npm run render              # out/frames/*.png → out/nutcracker.mp4  (--workers=3, --w/--h)
```

렌더는 헤드리스 Chromium의 소프트웨어 WebGL로도 됩니다(1080p 기준 프레임당 약 4초). 영화 전체가 시간 `t`의 순수 함수이므로 어느 프레임이든 같은 결과로 다시 뽑을 수 있습니다.

| 파일 | 내용 |
|---|---|
| `src/main.js` | 타임라인: 카메라 키프레임, 캐릭터 연기, 조명 전환, 파티클 |
| `src/characters.js` | 호두까기 인형, 클라라, 생쥐·생쥐왕, 사탕요정, 호두 배 |
| `src/world.js` | 거실, 바깥 마을, 하늘·달·별, 구름바다, 과자 왕국, 눈 |
| `src/gouache.js` | 과슈 후처리 패스와 타이틀 |
| `scripts/` | 정적 서버, 스틸·전체 렌더, 음악 합성 |

폰트는 SIL OFL 1.1 라이선스입니다(`fonts/OFL-NOTICE.txt`). 사용한 글자만 남겨 서브셋으로 넣었습니다.
