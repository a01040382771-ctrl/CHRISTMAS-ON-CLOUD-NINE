# 호두까기 인형 — 크리스마스 이브의 꿈 (30초 과슈풍 3D 애니메이션)

발레 《호두까기 인형》을 재해석한 30초 단편. 모든 모델·배경·음악은 코드로 만들었습니다(외부 이미지·음원 없음).
three.js로 3D 장면을 렌더링한 뒤, 후처리 셰이더로 **과슈(gouache)** 질감을 입힙니다.

결과물: [`nutcracker_gouache_30s.mp4`](nutcracker_gouache_30s.mp4) (1280×720, 24fps, 30초, AAC 스테레오)

## 스토리보드

| 시간 | 장면 | 내용 |
|---|---|---|
| 0.0–5.5 | 만남 | 거대한 꿈속 트리 아래, 호두까기 인형이 깨어나 클라라에게 걸어와 인사 → 손을 잡고 빛나는 창문으로 떠남 |
| 5.5–10.5 | 여행 | 호두 껍질 썰매를 타고 눈 내리는 푸른 밤 숲을 지남 |
| 10.5–15.5 | 눈꽃 요정 | 하늘에서 내려온 눈꽃 요정 7명이 두 사람 주위를 돌며 피루엣 |
| 15.5–21.5 | 생쥐 대왕 | 칼싸움 → 밀리는 호두까기 인형 → 클라라가 실내화를 던져 생쥐 대왕 명중, 연기로 사라짐 |
| 21.5–26.4 | 마법이 풀리고, 결혼식 | 황금빛 소용돌이 속에서 왕자로 변신 → 과자 나라 궁전 앞 꽃 아치 아래 결혼식 |
| 26.4–30.0 | 깨어남 | 흰빛으로 녹아들며 아침의 거실. 안락의자에서 잠든 클라라가 인형을 안고 깨어남 — "모든 것은 크리스마스 밤의 꿈이었어요" |

## 과슈 룩을 만드는 방법 (`src/post.js`)

1. **부드러운 셀 셰이딩** — 3단 그라데이션을 선형 보간한 `MeshToonMaterial`로 물감이 섞인 듯한 명암.
2. **방향성 쿠와하라 필터** — 붓결 방향장(노이즈)을 따라 샘플을 기울여 납작하고 불투명한 붓 터치를 만듦.
3. **안료 고임** — 명도 경계에 따뜻한 어두운 테두리(물감이 가장자리에 모이는 효과).
4. **붓결·얼룩·입자감** — 붓 방향 줄무늬, 고르지 않은 칠, 어두운 부분의 안료 입자.
5. **매트한 백색 안료감** — 살짝 탈채도하고 밝기를 들어 올려 분필 같은 불투명함.
6. **종이 결 + 찢긴 종이 테두리 + 따뜻한 비네트**.
7. **"보일(boil)"** — 12fps 간격으로 이미지가 미세하게 흔들려 손으로 다시 칠한 듯한 느낌.
8. 장면 전환은 **붓질 와이프**, 꿈에서 깨는 순간은 **흰빛 디졸브**.

## 다시 만들기

```bash
cd film/nutcracker
npm install                                   # three, 한글 서체(Gowun Batang)
NODE_PATH=$(npm root -g) node render.mjs      # frames/*.png (헤드리스 Chromium, 소프트웨어 WebGL)
python3 music.py score.wav                    # 오리지널 오르골/첼레스타 음악 합성 (numpy)
ffmpeg -framerate 24 -i frames/%05d.png -i score.wav -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a aac -b:a 192k -shortest nutcracker_gouache_30s.mp4
```

- 미리보기: 정적 서버로 `index.html`을 열면 실시간 재생, `index.html?t=17.5`는 해당 시점 정지 화면.
- 병렬 렌더: `node render.mjs --from 0 --to 240` 처럼 프레임 구간을 나눠 실행.
- 스틸: `node render.mjs --stills 3,13,20`.

## 파일

```
src/util.js        재질·키프레임·파티클·하늘 등 공통 도구
src/characters.js  클라라, 호두까기 인형/왕자, 생쥐 대왕·병정, 눈꽃 요정, 눈꽃
src/props.js       거실(밤/아침), 크리스마스 트리, 호두 썰매, 과자 궁전, 꽃 아치 등
src/shots.js       6개 장면의 연출(동작·카메라)과 타임라인
src/post.js        과슈 후처리 셰이더, 붓질 전환
src/main.js        타임라인 합성, 손글씨 자막, 미리보기/캡처 진입점
render.mjs         프레임 캡처 스크립트
music.py           음악 합성 스크립트
```
